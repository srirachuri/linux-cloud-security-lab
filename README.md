# 🐧 30 Days – Linux Practice 
## 📖 Overview

This repository contains my **30-day Linux practice journey**, covering Linux fundamentals, file management, permissions, networking, shell utilities, system administration, backups, and cloud security concepts, all through hands-on labs and mini-projects.

The goal of this repository is to build a strong Linux foundation for **Cloud Support, SOC Analyst, DevOps, and Cloud Security** roles.

## 📚 Topics Covered

### Days 1–10

* Linux commands and terminal basics
* File and directory management
* Viewing and editing files
* Searching files and text
* File permissions
* Users and groups
* Ownership and access control

### Days 11–20

* Sticky Bit
* umask
* sudo administration
* File ownership
* Permission auditing
* Security-focused Linux administration
* Real-world cloud security scenarios

### Days 21–30

* Backup and restore using `tar`
* Linux networking
* DNS troubleshooting
* Port scanning with Nmap
* Firewall basics (UFW)
* System monitoring
* Production-style Linux administration
* Cloud and security mini projects
